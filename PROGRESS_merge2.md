# Merge 2 progress log: Tier 2 into master (Tier 4 + performance + Tier 1)
Merge produced conflicts in app.py (34 hunks), docx_read (6), docx_tpl (2), pdf_write (4), ui (3), PARITY (2). Plan and why:
- Style cell, 24 bits: Tier 2's bits stay at their places, Tier 4's move up: ins 19, del 20, field kind 21-22, no proof 23. Sup and sub are one pair of bits used by both tiers. 2^24 is still exact in the 32 bit float bank.
- Glyphs: kept master's trees. New split: a metric tree per face (advance in ems, scaled by size, no ink visited), a pair tree for kerning that only fires when a pair exists, ink trees per drawn size and face entered only when drawing. Accented letters fire a base group plus shared delta group inside the ink tree. Colour planes keep master's lazy pixel gates but read Tier 2's 24 channel bit lines rather than one gate per palette colour.
- Squiggle moved from code 128 (now the Euro sign) to 129, which cp1252 leaves undefined.
- Palette: on the 4 bit grid; ribbon rectangles follow it so text backgrounds match. Index 5 stays hover gray, highlights move to 6..12.
- Paragraph props: one set at slots 3693..3698. Tier 1's ribbon and menus now step PIND, PSPA, PLSP through its op 6. Tier 2's op 6 undo states removed in favour of Tier 1's that keeps the caret; op 7 kept. Line record x0 keeps +48.
- Buttons: raw 54, 55, 35 stay global. Size box becomes raw 43 on Home (B[63]); Tier 2's grids become raw 44 on Home and raw 45 on Layout through TB(id,tab). Typed size moved from mode 6 (mail merge took it) to mode 7.
- Layout grid moved to x=590 since Tier 1's Layout ribbon occupies the old spot; size box and grow button moved in Tier 1's ribbon. So test geometry constants changed: tier2.js LX, (245,75) to (205,75), (192,75) to (251,75); e2e lay() base. Only coordinates changed.
- Writer: t2_write's XML, with Tier 4's wrappers for ins, del, fields; deflate is now a subroutine used for both styles.xml and document.xml. Hash table moved to 50000 as the style table takes 40000.
- Reader: Tier 2's three passes, plus Tier 4's ins, del, fldSimple, noProof, delText. Added character styles to the table for rStyle (Tier 4 test needs them), flagged so the writer skips them. Normal's space after is cleared on open so a file with no pPr means zero spacing in both the styled and unstyled case.
- Found while merging: spell checker now treats accented words as unchecked and curly apostrophe as apostrophe. Fonts in the PDF now carry the full cp1252 set, with a few glyphs grafted from the Latin extended files.
- Found while merging, not fixed here: Tier 2 hanging indents store negative values through relu gates, which clamp to zero, so negative first line offsets are lost. Same behaviour as Tier 2 alone.
